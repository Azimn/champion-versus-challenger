# Champion versus Challenger

A research workspace for identifying, qualifying, comparing, and recombining proven non-LLM mechanisms for believable simulated characters.

The project does not begin by inventing a cognitive architecture. It begins with software archaeology. Existing implementations are treated as evidence; new mechanisms are treated as hypotheses that must earn their place experimentally.

The target is a lightweight autonomous character whose apparent individuality emerges from persistent simulation: choices, routines, relationships, avoidance, preferences, memory, goals, mistakes, adaptation, conflicts, habits, spontaneous activity, social expectations, and accumulated consequences. Natural-language generation is optional and must never be the source of the character's apparent mind.

See `PROTOCOL.md` for the authoritative research protocol.

Permanent project memory lives in:

- `research/PROJECT_CATALOG.md`
- `research/MECHANISM_CATALOG.md`
- `research/EXPERIMENT_LEDGER.md`
- `research/CHAMPION_LINEAGE.md`

The first milestone is not a new persona implementation. It is to identify, obtain, execute, adapt, and behaviorally compare the strongest practical non-LLM character simulations we can find.
