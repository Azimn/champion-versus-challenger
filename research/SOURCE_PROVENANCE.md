# Source Provenance

This file records the evidence used to seed the project and mechanism catalogs. It is not a substitute for experiment results. Access date for the initial entries is 2026-09-15.

## PC-001 Ensemble

**Repository:** https://github.com/ensemble-engine/ensemble  
**Pinned archaeology revision:** `8b74bdec4ba2ef4e14795b7591df3b5d73f283e3`  
**README evidence:** Project describes Ensemble as a framework for socially aware characters and an evolution of Comme il Faut from Prom Week.  
**Runnable artifacts inspected:** `examples/loversAndRivals/`, `tests/`, `build-library.js`, shipped `examples/loversAndRivals/ensemble.js`.  
**License evidence:** `LICENSE.md`, BSD 4-clause University of California variant.  
**Qualification note:** The shipped Lovers and Rivals bundle is preferred over regenerating it because the historical build script performs asynchronous appends that can reorder bundle modules on a modern host.

## PC-002 FAtiMA Toolkit

**Repository:** https://github.com/GAIPS/FAtiMA-Toolkit  
**README evidence:** Toolkit for characters and robots with social and emotional intelligence, continuing the FAtiMA architecture lineage.  
**Runnable artifacts inspected:** solution files, `Applications/`, `Assets/`, `Components/`, `Tests/`, `Tutorials/`.  
**License evidence:** `License.txt`, Apache License 2.0.

## PC-003 PsychSim

**Repository:** https://github.com/pynadath/psychsim  
**README evidence:** Open-source social simulation using decision-theoretic agents with Theory of Mind.  
**Runnable artifacts inspected:** Python package, documentation, social-domain examples and negotiation-related scenarios.  
**License evidence:** `LICENSE.txt`, MIT License.

## PC-004 inBloom

**Repository:** https://github.com/cartisan/inBloom  
**README evidence:** Computational storyteller built on an affective extension of Jason BDI, with Big Five personality, OCC emotions, mood, and affect-sensitive plan selection.  
**Runnable artifacts inspected:** `little_red_hen.mas2j`, Java source, Maven project, documented `RedHenLauncher` workflow.  
**License evidence:** `LICENSE`, GNU GPL 3.0.

## PC-005 MicroPsi2

**Repository:** https://github.com/joschabach/micropsi2  
**README evidence:** Toolkit implementing concepts from the MicroPsi cognitive architecture. Historical instructions target Python 3.4 and 3.5 and document optional Theano and spock dependencies.  
**Runnable artifacts inspected:** run script, server entry point, tests, demo data, browser interface.  
**License evidence:** `license.txt`, MIT unless otherwise marked in individual files.

## PC-006 GAMYGDALA

**Repository:** https://github.com/broekens/gamygdala  
**README evidence:** JavaScript emotion engine for games with examples and engine-independent core use.  
**License evidence:** `LICENSE`, MIT License.

## PC-007 openc2e / Creatures lineage

**Repository:** https://github.com/openc2e/openc2e  
**README evidence:** Open reimplementation of the Creatures engine with modern build instructions. Current status identifies working agents and creature biochemistry while full creature support remains incomplete.  
**License evidence:** LGPL-2.1 for openc2e. Original Creatures game data and assets are separate proprietary material and are not treated as part of this license.

## PC-008 Oz / Hap / Em

**Primary archive:** https://www.cs.cmu.edu/Groups/oz/  
**Evidence inspected:** Oz project pages, believable-agent publications, theses, and historical descriptions of Hap and Em.  
**Source status:** No authoritative, reusable, currently runnable source distribution and license have yet been established. Code reuse is blocked pending provenance.

## PC-009 ABL / Facade lineage

**Primary research pages:** https://www.cs.cmu.edu/~michaelm/publications/  
**Evidence inspected:** ABL and Facade research publications describing reactive planning, joint goals, and believable-agent coordination.  
**Source status:** No authoritative complete reusable implementation and license have yet been established. Code reuse is blocked pending provenance.

## Provenance rule

Every future catalog entry must identify where its claims came from. Every candidate used in an experiment must additionally pin an immutable release or commit. Mirrors are discovery aids only until provenance and licensing are established.
